# Motion

The jelly feel comes from two config groups: `pillJelly` (the indicator's
spring/snap behaviour) and `distortion` (how the whole track squishes and follows
your finger). Both are deep-partial.

```tsx
<JellyTabBar
    {...props}
    config={{
        pillJelly: {
            pressedScale: 1.3, // how much the pill inflates while pressed
            snapOnPointerDown: true, // jump toward the touch immediately
        },
        distortion: {
            pressedScale: 1.025, // whole-track scale while pressed
        },
    }}
/>
```

## `pillJelly` springs

Each channel is a `{ stiffness, dampingRatio }` spring:

| Spring | `stiffness` | `dampingRatio` |
| --- | --- | --- |
| `panel` | `300` | `1` |
| `press` | `1000` | `1` |
| `scaleX` | `250` | `0.6` |
| `scaleY` | `250` | `0.7` |
| `value` | `1000` | `1` |
| `velocity` | `300` | `0.5` |

```tsx
config={{
    pillJelly: {
        frameConfig: {
            releaseDistanceFraction: 0.025,
            springs: { scaleX: { stiffness: 200, dampingRatio: 0.5 } },
        },
    },
}}
```

## `distortion`

| Key | Default | Description |
| --- | --- | --- |
| `pressedScale` | `1.025` | Whole-track scale while pressed. |
| `spring.damping` | `18` | Distortion spring damping. |
| `spring.mass` | `0.9` | Distortion spring mass. |
| `spring.stiffness` | `240` | Distortion spring stiffness. |
| `verticalDrag.distortion` | `0.08` | How much vertical drag squishes the track width. |
| `verticalDrag.distanceForMaxDistortion` | `700` | Drag distance (px) for max distortion. |
| `verticalDrag.follow` | `0.25` | How much the track follows the finger vertically. |
| `verticalDrag.rubberBand` | `0.14` | Rubber-band resistance on the vertical follow. |

:::tip
Need a complete, mutable config object? Call `resolveTabBarConfig(partial?)`.
:::
