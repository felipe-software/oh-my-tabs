# Touch feedback

A soft radial glow follows your finger. It defaults to `colors.selectedSurface`.

```tsx
<JellyTabBar
    {...props}
    touchFeedbackColor="#38BDF8"
    touchFeedbackOpacity={0.15}
    touchFeedbackScale={2}
/>
```

<StorybookPreview id="customization-touch--custom-color" height={340} />

## Turn it off

```tsx
<JellyTabBar {...props} touchFeedbackEnabled={false} />
```

<StorybookPreview id="customization-touch--off" height={320} />

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `touchFeedbackEnabled` | `true` | Toggles the radial feedback. |
| `touchFeedbackColor` | `colors.selectedSurface` | Overrides the glow color. |
| `touchFeedbackOpacity` | `0.15` | Base opacity. |
| `touchFeedbackScale` | `2` | Multiplier applied to the radius. |
