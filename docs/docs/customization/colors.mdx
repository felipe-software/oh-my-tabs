# Colors

`colors` takes solid React Native color strings. Partial objects merge over the
defaults, so you usually only set the pill color and let the neutral surface stay.

```tsx
<JellyTabBar
    {...props}
    colors={{
        surface: "#1C1917", // track background
        selectedSurface: "#F59E0B", // selected pill
        activeContent: "#451A03", // selected icon / label
        inactiveContent: "#A8A29E", // unselected icon / label
    }}
/>
```

## Defaults

| Key | Default | Role |
| --- | --- | --- |
| `surface` | `#22211f` | Track background |
| `selectedSurface` | `#f2eee7` | Selected pill |
| `activeContent` | `#11100f` | Selected icon / label |
| `inactiveContent` | `#b8b4ad` | Unselected icon / label |

## Opacity

`opacity` controls those same four layers independently, clamped `0`–`1`. It
applies to the rendered content, so the animated pill keeps a fully opaque
clipping shape.

```tsx
<JellyTabBar {...props} opacity={{ surface: 0.85 }} />
```
