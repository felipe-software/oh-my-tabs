# Backdrops

`backdrop` and `selectedBackdrop` are React nodes rendered **below** the track and
selected-pill color layers. This keeps blur provider-agnostic — inject whatever
blur component your platform uses.

```tsx title="With expo-blur"
import { BlurView } from "expo-blur";

<JellyTabBar
    {...props}
    backdrop={<BlurView intensity={35} tint="dark" style={StyleSheet.absoluteFill} />}
    selectedBackdrop={<BlurView intensity={20} tint="light" style={StyleSheet.absoluteFill} />}
/>;
```
